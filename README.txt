Yapper (Unofficial Desktop App)

An unofficial Windows desktop app for yapper.website. Not affiliated with Yapper.

Download & Run (Windows)
Go to the Releases page of this repo and download Yapper.zip.
Right-click the zip and choose Extract All. Don't run it from inside the zip.
Open the extracted folder and run Yapper.exe.
Log in with your own Yapper account.

Pin to taskbar: open the app, right-click its taskbar icon, then choose Pin to taskbar.

"Windows protected your PC" warning: the app isn't code-signed. Click More info, then Run anyway.

No other software needed. You just need Windows 10/11 (64-bit) and an internet connection.

Run From Source

Requires Node.js.

git clone https://github.com/TGPG-Studios/Yapper-App-Unofficial-.git
cd Yapper-App-Unofficial-
npm install
npm start
Build Your Own
npm run build

The app appears in dist/win-unpacked/Yapper.exe. Run the terminal as Administrator if the build fails.
